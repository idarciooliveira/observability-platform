What this phase establishes

The platform team owns shared ingestion, storage, identity, and access. Project teams instrument applications and run local collectors. Phase 1 uses one deployment host with multi-tenancy by design.

Ownership boundary

Project teams own application instrumentation and service dashboards. The platform team owns shared ingestion, storage, tenant isolation, Grafana access, quotas, retention, backups, and platform alerts.

Implementation notes

        

          

            
Start with one host

            
Run gateway and collector replicas across failure domains. Keep state in object storage or managed databases, not container filesystems.

          

          

            
Identity has two paths

            
Keycloak authenticates Grafana users. mTLS or short-lived machine credentials authenticate project telemetry.

          

          

            
Tenant identity is authoritative

            
The collector maps credentials to a project and overwrites or ignores any client-supplied project ID.
