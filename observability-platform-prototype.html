What this phase establishes

The platform team owns shared ingestion, storage, identity, and access. Project teams instrument applications and run local collectors. Phase 1 uses one deployment host with multi-tenancy by design.

Implementation notes

        

          

            
Gateway is the trust boundary

            
otel-gateway:4318 is the sole public ingress. It enforces Bearer auth, refuses to start without tokens, and answers 401 without forwarding anything.

          

          

            
Identity has two paths

            
Keycloak OIDC plus Grafana RBAC for humans. One Bearer token per project for machines, mapped to a tenant by the gateway.

          

          

            
Tenant identity is authoritative

            
Each credential routes to a private pipeline whose transform overwrites project.id, and whose exporters attach a static X-Scope-OrgID. Spoofed IDs cannot cross tenants; 18 tests prove it.
